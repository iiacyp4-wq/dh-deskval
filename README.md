# DH의 탁상감정

감정평가사의 탁상감정(약식 검토)을 돕는 웹 워크시트입니다.
물건개요 → 자료조사 체크리스트 → 가격산정(거래사례비교법·공시지가기준법·원가법·수익환원법) → 담보검토(LTV·방공제·선순위 차감) → 검토서 출력 순서로 진행합니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 저장소를 GitHub에 올립니다.
2. https://share.streamlit.io 에서 GitHub 계정으로 로그인합니다.
3. "Create app" → 이 저장소, 브랜치 `main`, 파일 `app.py`를 선택합니다.
4. 원하는 주소(예: `dh-deskval`)를 정하면 `https://dh-deskval.streamlit.app` 형태로 공개됩니다.

## 유의사항

- 현장조사 없이 공부·시세자료로 하는 약식 검토 도구이며, 정식 감정평가서를 대체하지 않습니다.
- 원가법의 구조별 재조달원가 단가는 예시값입니다. 실무 단가표로 수정해 쓰세요.
- 최우선변제금 기준표는 주택 2023.2.21, 상가 2014.1.1 시행 기준입니다. 개정 시 화면에서 금액을 수정하세요.
- 입력 내용은 사용자 브라우저에만 저장됩니다(서버 저장 없음).
